## مقدمة

لينكس نظام تشغيل **مفتوح المصدر** قوي ومجاني!

> **معلومة:** معظم خوادم الإنترنت تعمل على لينكس!

---

## الأوامر الأساسية

### عرض الملفات
```bash
# عرض الملفات
ls -la

# الانتقال لمجلد
cd /home/user

# إنشاء مجلد
mkdir new_folder
```

### إدارة الحزم (Ubuntu)
```bash
# تحديث النظام
sudo apt update && sudo apt upgrade

# تثبيت برنامج
sudo apt install firefox
```
