## أدوات Git الأساسية 🔀
```bash
# إعداد Git
git config --global user.name "اسمك"
git config --global user.email "email@example.com"

# الأوامر الأساسية
git init
git add .
git commit -m "رسالة"
git push origin main
```

> **تحذير:** لا تنسَ عمل commit قبل push!
