## محررات الأكواد

### VS Code ⭐
أفضل محرر للمطورين، مجاني ومفتوح المصدر.
```bash
# تثبيت VS Code على فيدورا
sudo rpm --import https://packages.microsoft.com/keys/microsoft.asc
sudo dnf install code
```

### الامتدادات الضرورية

1. **Prettier** - تنسيق الكود
2. **ESLint** - فحص الأخطاء
3. **GitLens** - إدارة Git

## أدوات Terminal

- **Oh My Zsh** - لتحسين الـ Terminal
- **tmux** - لتقسيم الشاشة
- **htop** - لمراقبة النظام
