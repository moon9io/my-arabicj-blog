# ✍️ My Arabic Blog (my-arabicj-blog)

[![Live Blog](https://img.shields.io/badge/blog-online-blue.svg?style=for-the-badge&logo=hugo&logoColor=white)](https://moon9io.github.io/my-arabicj-blog/)

A personal blog built with **Hugo** and the **Blowfish** theme, specifically tailored for Arabic content with full RTL (Right-to-Left) support.

## 🚀 Features
- **RTL Support**: Fully optimized for Arabic reading experience.
- **High Performance**: Static site generation with fast loading times.
- **Clean Design**: Minimalist and modern aesthetic.
- **SEO Optimized**: Built-in best practices for search engine visibility.

## 🛠 Built With
- [Hugo](https://gohugo.io/) - The world's fastest framework for building websites.
- [Blowfish Theme](https://blowfish.page/) - A powerful and flexible theme for Hugo.

## 📝 Content
This blog features articles about technology, tourism, and personal insights.
