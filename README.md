# ✍️ مدونتي العربية | My Arabic Blog

مدونة شخصية مخصصة للمحتوى العربي، أشارك فيها مقالات حول التقنية، البرمجة، نصائح، شروحات، والمزيد. تم بناء المدونة باستخدام [Hugo](https://gohugo.io/)، وهو إطار عمل سريع وقوي لإنشاء المواقع الثابتة.

**English:** A personal blog dedicated to Arabic content, where I share articles about technology, programming, tips, tutorials, and more. The blog is built using Hugo, a fast and powerful static site generator.

---

## ✨ الميزات الرئيسية | Key Features

- **محتوى عربي أصيل:** مقالات متنوعة باللغة العربية.
- **مدونة ثابتة:** أداء عالٍ وسرعة تحميل فائقة بفضل Hugo.
- **تصميم نظيف:** واجهة مستخدم بسيطة ومركزة على المحتوى.
- **سهولة التصفح:** تنظيم المقالات حسب التصنيفات والوسوم.

---

## 🚀 البدء السريع | Quick Start

### التثبيت (إذا كنت ترغب في تشغيلها محلياً)

يتطلب تشغيل المدونة محلياً تثبيت [Hugo](https://gohugo.io/getting-started/installing/).

```bash
# استنساخ المستودع
git clone https://github.com/moon9io/my-arabicj-blog.git

# الدخول للمجلد
cd my-arabicj-blog

# تشغيل الخادم المحلي
hugo server
```

بعد ذلك، يمكنك الوصول إلى المدونة عبر `http://localhost:1313/` في متصفحك.
